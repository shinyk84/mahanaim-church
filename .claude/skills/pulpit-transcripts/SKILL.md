# 강단 녹취 업데이트

사용자가 "강단 녹취 업데이트해줘"라고 하면 아래 순서대로 끝까지 처리하고, 마지막에 확인이 필요한 부분을 보고한다.
범위 지정이 없으면 **녹취가 없는 강단 영상 전부**(보통 지난 녹취 이후 것)를 대상으로 한다. "주일만", "11/8 2부" 같은 지정이 있으면 따른다. 언어는 기본 ko·en·ur, 추가 언어를 요청하면 함께 만든다.

## 1. 대상 확인 · 자막 받기
```
git pull --rebase origin main            # GitHub 자동 업데이트가 추가한 영상 먼저 받기
python scripts/transcripts.py pending    # 녹취 없는 영상
python scripts/transcripts.py fetch <ID...>   # .transcript-work/<ID>.txt (git에 안 올라감)
```
자막이 없으면(방금 끝난 라이브 등) 몇 시간 뒤 다시 시도하라고 사용자에게 알린다.

## 2. 영상마다 에이전트 1개 (병렬)
각 에이전트에게: 자막 파일 경로, 영상 날짜·예배(새벽/주일1부/주일2부/기타)·제목·설교자, 출력 경로를 주고 아래 규칙을 그대로 전달한다.

출력: `content/transcripts/pulpit/<ID>/ko.md`, `en.md`, `ur.md`, `titles.json`(`{"en": "...", "ur": "..."}` — 영상 제목 번역)

- **ko.md**: 설교 본문만(사도신경·찬양·광고·헌금·축도 제외, 본문 봉독은 맨 위 인용문 가능). 말한 내용에 충실하게, 군더더기·자막 오류만 정리. 이 운동의 용어로 오인식 교정: 보좌, 망대, 절대망대, 렘넌트, 렘넌트중직자, 237, 5000종족, 서밋, 다락방, 마가다락방, 산업선교, 전도제자, 언약, 오직·유일성·재창조, RT, CVDIP, 3시대, 24·25·00, 300%, 7망대·7여정·7이정표, 흑암, 재앙, 현장, 팀사역, 미션홈, 금토일 시대. 알아들을 수 없으면 추측하지 말고 (…). `##` 소제목은 설교자의 흐름(서론/1./2./결론 등)대로, 문서 제목은 넣지 않음. 성구는 `사도행전 1:8`처럼 일반 표기. 거친 표현은 순화하되 내용은 바꾸지 않는다. 뜻이 뒤집힐 수 있는 수정은 하지 말고 보고한다.
- **en.md**: 같은 구조의 충실한 영어 번역. 성구 `Acts 1:8`. 용어: 망대 Bartizan, 여정 Journey, 이정표 Guidepost, 보좌 The Throne, 3시대 3 Eras, 렘넌트 Remnant, 마가다락방 Mark's Upper Room, 절대망대 Absolute Bartizan, 서밋 Summit (숫자 237·300%·24·25·00 그대로).
- **ur.md**: 같은 구조의 우르드어 번역(우르드 문자). 성구는 반드시 `[[ACT 1:8]]` 형식, 책 코드는 `assets/config.js` 기준(요한복음 JOH, 에스겔 EZE, 빌립보서 PHI). 용어: 망대 بُرج, 여정 سفر, 이정표 سنگِ میل, 보좌 تخت, 3시대 3 زمانے, 마가다락방 مرقس کا بالاخانہ, 렘넌트 ریمننٹ.
- 마크다운은 `#`/`##`, `-`, `1.`, `>`, `---`, `**굵게**`만. 다른 파일은 건드리지 않는다.
- 끝나면 보고: 소제목 목록, 뺀 예배 순서, (…) 위치, 확신 없는 판독(이름·숫자·뜻이 바뀔 수 있는 곳).

## 3. 반영 · 확인 · 배포
```
python scripts/transcripts.py register   # tr·titles 반영 + 잘못된 책 코드 자동 교정/경고
```
- `python -m http.server 8000` 으로 띄워 `#/ko/pulpit/v_<ID>`, `#/en/...`, `#/ur/...`가 열리는지, 우르드어 성구 버튼이 생기는지 확인(Playwright 스크린샷).
- 커밋 → `git pull --rebase origin main` → `git push` → 실제 사이트(https://mahanaim-church.vercel.app/content/videos/pulpit.json)에 tr이 반영됐는지 확인.

## 4. 사용자에게 보고
영상별로 완료 여부와, 에이전트가 보고한 **확인이 필요한 부분**(특히 뜻이 반대로 될 수 있는 문장, 사람 이름, 성구 번호 추정)을 짧게 정리한다.
